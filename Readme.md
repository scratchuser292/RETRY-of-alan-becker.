# 🌟 RETRY of Alan Becker

Welcome to the official **RETRY of Alan Becker**! 

This repository is a full revival/recreation of the amazing (but unfortunately deleted) project originally created by **swtqq**. Since the original was lost, I decided to step up, rebuild it from the ground up, and bring it back to life so the community can enjoy it again!

## 🎬 About the Project
This project is heavily inspired by the legendary **Alan Becker** (creator of *Animator vs. Animation*, *Animation vs. Minecraft*, etc.). It brings the classic stick-figure action, animations, and gameplay back to life. 

Whether you are here for the nostalgia or experiencing it for the first time, this "retry" aims to capture all the magic of swtqq's original work while ensuring it runs smoothly today.
